# Voxly

> Your voice, not AI's voice.

An AI text rewriter as a Chrome extension. Select any text on any page, right-click, pick a tone, get a rewrite that keeps your writing style instead of flattening it into generic AI prose.

Built as a solo-founder project targeting the North American market.

---

## Status

Working end to end: the Next.js app builds and serves, the rewrite API is wired to OpenAI, and the Chrome extension loads unpacked. Payments and Style Learning are not implemented yet.

## Getting started

**Requirements:** Node 18+, a Supabase project, an OpenAI API key, Chrome.

```bash
npm install
cp .env.example .env.local   # then fill in the values
```

**Set up the database** — in the Supabase SQL editor, run `supabase/schema.sql`.

**Run the web app:**

```bash
npm run dev        # http://localhost:3000
npm run build      # production build
npm start          # serve the production build
```

**Load the extension:**

1. Edit `chrome-extension/config.js` — set `apiBase` to your deployed web app
   URL, plus your Supabase URL and anon key. (It must match `host_permissions`
   in `manifest.json`, otherwise the extension can't read the login cookie.)
2. Open `chrome://extensions/`
3. Turn on Developer mode
4. Load unpacked → select `chrome-extension/`
5. Select text on any page → right-click → **Rewrite with Voxly**

No build step is needed for the extension; `chrome-extension/` is loaded as-is.

## Configuration

| Variable | Used by |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Browser + server |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Browser |
| `SUPABASE_SERVICE_ROLE_KEY` | `app/api/rewrite` only — never exposed to the client |
| `OPENAI_API_KEY` | `app/api/rewrite` only |

`GET /api/health` reports which of these are present, which is the quickest way to confirm your `.env.local` is wired up.

Without Supabase configured the dashboard renders a setup notice instead of crashing.

## API

### `POST /api/rewrite`

Requires an `Authorization` header carrying a Supabase access token.

```jsonc
// request
{ "text": "hey can u send me the doc asap", "tone": "professional" }

// response
{ "result": "Could you please send me the document at your earliest convenience?" }
```

`tone` is one of `professional`, `casual`, `academic`, `persuasive`, `concise`.

Errors: `401` no session, `402` out of credits, `413` text over 5000 chars, `502` upstream AI failure.

## Pricing model

Free: 50 rewrites/day. Pro: $19 one-time for unlimited. Credit packs for occasional use.

The one-time price is deliberate — the main complaint about incumbent tools is subscription fatigue plus paywalls that appear after you have already committed.

## Notes

- The content script runs on `<all_urls>` but only activates on an actual text selection.
- The OpenAI key never reaches the browser; all rewrites go through `/api/rewrite`.
- Row Level Security on every table — users can only read their own rows.
- `supabase/functions/rewrite-text/` mirrors the API route for anyone who prefers Edge Functions. It is excluded from the Next.js TypeScript program since it targets the Deno runtime.
