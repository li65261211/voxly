# Voxly

> Your voice, not AI's voice.

An AI text rewriter as a Chrome extension. Select any text on any page, right-click, pick a tone, get a rewrite that keeps your writing style instead of flattening it into generic AI prose.

Built as a solo-founder project targeting the North American market.

---

## Status

Working end to end: the Next.js app builds and serves, the rewrite and style extraction APIs are wired to Groq / OpenAI, **Style Learning is fully operational**, and the Chrome extension loads unpacked. Payments (Stripe) are planned next.

## Getting started

**Requirements:** Node 18+, a Supabase project, a Groq or OpenAI API key, Chrome.

```bash
npm install
cp .env.example .env.local   # then fill in the values
```

**Set up the database** — in the Supabase SQL editor, run `supabase/schema.sql`.

**Run the web app:**

```bash
npm run dev        # http://localhost:3000
npm run build      # production build
npm start          # serve the production build
```

**Deploying to Vercel (100% Free Hobby Tier):**

1. Push your repository to GitHub.
2. Import the repo into Vercel.
3. In Vercel Project Settings → Environment Variables, add:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `GROQ_API_KEY`
4. Deploy! Your app will be live at `https://your-app.vercel.app`.
5. In `chrome-extension/config.js`, set `apiBase: 'https://your-app.vercel.app'`.

**Load the extension:**

1. Edit `chrome-extension/config.js` — set `apiBase` to your deployed web app
   URL (or `http://localhost:3000`), plus your Supabase URL and anon key.
2. Open `chrome://extensions/`
3. Turn on Developer mode
4. Load unpacked → select `chrome-extension/`
5. Select text on any page → right-click → **Rewrite with Voxly** (or click the floating icon)

## API

### `POST /api/style`

Analyze personal writing samples and extract the user's authentic **Style DNA**.

```jsonc
// request
{
  "samples": [
    "Hey team! Quick update on the rollout: we squashed the latency bug on the edge workers...",
    "I appreciate you digging into this. My main concern is user intuition rather than tech cost."
  ]
}

// response
{
  "success": true,
  "styleProfile": {
    "voice_name": "Crisp & Direct Tech Communicator",
    "cadence": "Short, punchy sentences with active verbs",
    "formality": "Approachable, conversational, and direct",
    "vocabulary_level": "Modern everyday English without corporate jargon",
    "signature_habits": "Direct sign-offs and concise phrasing",
    "forbidden_words": ["delve", "testament", "pivotal", "furthermore"],
    "prompt_instruction": "Rewrite with punchy clarity, avoiding filler words.",
    "analyzed_at": "2026-10-01T..."
  }
}
```

### `POST /api/rewrite`

Requires an `Authorization` header carrying a Supabase access token.

```jsonc
// request (supports 'my_voice', 'professional', 'casual', 'academic', 'persuasive', 'concise')
{ "text": "hey can u send me the doc asap", "tone": "my_voice" }

// response
{ "result": "Could you send over the document when you get a chance?" }
```

Errors: `400` invalid input / voice not trained yet, `401` no session, `402` out of credits, `413` text over 5000 chars, `502` upstream AI failure.

The one-time price is deliberate — the main complaint about incumbent tools is subscription fatigue plus paywalls that appear after you have already committed.

## Notes

- The content script runs on `<all_urls>` but only activates on an actual text selection.
- The OpenAI key never reaches the browser; all rewrites go through `/api/rewrite`.
- Row Level Security on every table — users can only read their own rows.
- `supabase/functions/rewrite-text/` mirrors the API route for anyone who prefers Edge Functions. It is excluded from the Next.js TypeScript program since it targets the Deno runtime.
